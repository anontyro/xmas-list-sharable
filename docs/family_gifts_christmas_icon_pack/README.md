# Family Gifts — 36 Christmas App Icons

Three collections: `christmas/`, `shopping/`, `interface/`. Each holds 12 individually separated 384x384 PNG files with **approximate automated transparency**. Because the source art uses atmospheric gradient glows, some transparent cutouts lose small details or have uneven boundaries.

For **fully intact art**, use `background_preserved/` (36 individual unmodified square/rectangular source crops retaining their colored backgrounds). `sheets/` contains the three full source sheets and `all_icons_preview.png` shows the transparent cutouts.

Use PNGs in your Next.js `public/icons/` folder. The files are raster art, not SVG.
